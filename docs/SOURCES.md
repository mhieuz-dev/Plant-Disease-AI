# Advisory corpus sources

The advisory module retrieves passages from documents placed in `docs/<crop>/`. The third-party publications are **not redistributed** in this repository, because their copyright belongs to their authors and publishers. To rebuild the corpus, obtain each document from its publisher (the DOI link where one exists, otherwise search by the description) and save it under the file name given below. The files ending in `_supplement.txt` were written by the authors of this repository and are included.

Descriptions are in Vietnamese, as used for the citations shown to users.
